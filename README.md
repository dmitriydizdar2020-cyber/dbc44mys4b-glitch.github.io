# MONTBLANC · personal growth app

This **public** repository contains application code only. It must never contain personal diary entries, credentials, or backup archives.

The application files are in `life-os/`.

To install on an iPhone, enable GitHub Pages from the `main` branch in **Settings → Pages**.

Private encrypted records require a **separate private repository** named `montblanc-private-data`, restricted GitHub access, and a separate vault password. The vault password is not recoverable from GitHub.
